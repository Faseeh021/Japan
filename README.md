# KANTO水道サービス LP

Static HTML/CSS landing page for KANTO水道サービス (water leak & drain clog repair service). No frameworks, no build tools — plain HTML and CSS only.

## Structure

```
kanto-suido-lp/
├── index.html
├── css/
│   └── style.css
├── assets/
│   ├── images/
│   ├── icons/
│   └── fonts/
└── README.md
```

## Preview locally

Just open the file directly in a browser:

```
open index.html
```

Or serve it so relative paths behave exactly as they will in production:

```
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.
